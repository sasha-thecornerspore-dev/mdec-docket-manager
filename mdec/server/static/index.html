Harvest the docket

The portal challenges automated browsing, so the reliable route is to get there yourself and then hand over. Downloads and the folder are settled before any clicking starts.

  1. Open portal window — sign in, clear any verification, and open your case so the docket is on screen.
  2. Check readiness — confirms the folder is writable, multiple downloads are pre-approved, and the docket parses.
  3. Harvest from this page — downloads everything not already on disk, paced, without navigating away.

    Repair a legacy folder

    Renames an old dump folder (files still named Title-caseid (2).pdf) into the NNNN_YYYYMMDD_Description.pdf catalog, matching the Nth copy of a title to the Nth docket slot expecting it. Sorted by file creation time, which equals download order. Always dry-run first. Once names carry sequence numbers, "Adopt files" on the Dashboard can link them.
